Generated by `neqsim surf-study --demo --out demo`. All inputs are synthetic
(`devtools/surf_examples/four_well_tieback/study.yaml`); nothing here describes a real field.

| File | Content |
|------|---------|
| [SURF-SYN-001_drawings.pdf](SURF-SYN-001_drawings.pdf) | The 15 A3 drawing sheets (field plan, network schematic, functional process sheets, route profiles, riser, template and PLEM/PLET arrangement, jumpers, umbilical, thermal cross-sections, installation sequence, results, concept comparison, quantities) |
| [validation_report.md](validation_report.md) | The fail-closed validation report of the run (readiness SCREENING) |

The demonstration compares a daisy chain (A), dual direct flowlines (B) and a daisy chain with an 8-inch trunk (C) across
plateau, turndown and late-life cases. Concept C is cheaper than A but fails the pressure-drop, hydrate-margin and
erosion criteria in the plateau case, so it is reported infeasible and not ranked; A is selected. The network is solved
with live production and injection wells. One solver limitation is carried openly: the generic Darcy edge energy
balance omits elevation work, which shifts the injection-riser arrival temperature by about 0.8 K (reported as an
explained hand-check deviation, not a pass).

The Word report, dataset, model builders and the SVG/PNG sheets are regenerated by the command above (about ten minutes
for the first solve) and are not stored in the repository. See
[SURF_DESIGN_STUDY.md](../../development/SURF_DESIGN_STUDY.md).
