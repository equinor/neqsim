Get up and running with NeqSim in 5 minutes. Choose your platform:

> **Documentation Version:** These guides are for NeqSim 3.x. Check the [Maven Central](https://central.sonatype.com/artifact/com.equinor.neqsim/neqsim) page for the latest version number.

| Platform | Best For | Time to First Calculation |
|----------|----------|---------------------------|
| [Java Quickstart](java-quickstart.md) | Production applications, full API access | ~10 minutes |
| [Python Quickstart](python-quickstart.md) | Data science, scripting, Jupyter notebooks | ~5 minutes |
| [Google Colab](colab-quickstart.md) | No installation, instant start | ~1 minute |

## Which Should I Choose?

| Goal | Recommended path |
|------|------------------|
| Try NeqSim immediately without installing anything | [Google Colab Quickstart](colab-quickstart.md) |
| Use NeqSim from Python, data-science tools, or notebooks | [Python Quickstart](python-quickstart.md) |
| Build a production Java application with full API access | [Java Quickstart](java-quickstart.md) |
| Extend NeqSim or contribute to the repository | [Java Quickstart](java-quickstart.md) and [Developer Setup](../development/DEVELOPER_SETUP.md) |
| Use AI agents to solve and document an engineering problem | [Solve an Engineering Task](../tutorials/solve-engineering-task.md) |
